# `=this.file.name`
Der [[Schwierigkeitsgrad]] einer Tätigkeit gibt an wie schwer diese auszuführen ist.
Der angegebene Wert muss bei einem W20-Wurf  mindestens erreicht oder überboten werden, damit die Tätigkeit erfolgreich ausgeführt wird. 

| Schwierigkeit  | SG  |
| -------------- | :-: |
| Sehr einfach   | 5   |
| Einfach        | 10  |
| Mittel         | 15  |
| Schwer         | 20  |
| Sehr schwer    | 25  |
| Fast unmöglich | 30  |
