# `=this.file.name`
Ein unverschlossenes Hindernis zu überwinden (eine offene Tür durchschreiten) ist eine kleine Handlung, siehe [[Erkundungsrunde#Kleine Handlungen]].
Ist das Hindernis dagegen ein echtes Problem, ist das Überwinden eine eigene [[Erkundungsaktionen|Erkundungsaktion]].

Beispiele:
- ein Schloss knacken ([[Fingerfertigkeit]])
- eine verklemmte Tür aufbrechen ([[Athletik]])
- eine [[Fallen|Falle]] entschärfen ([[Fingerfertigkeit]] oder [[Nachforschung]])
- aus einer Grube klettern ([[Athletik]])
- einen schweren Gegenstand beiseiteschaffen ([[Athletik]])
- ein Rätsel lösen ([[Nachforschung]] oder ein passender [[Attribute#Attributswurf]])
- einen Gegenstand reparieren

Wo genau die Grenze zwischen einer kleinen Handlung (ein Pfeil aus der Wand ziehen) und einer vollen [[Erkundungsaktionen|Erkundungsaktion]] (herausfinden, welches der zwölf Symbole am Boden sicher zu betreten ist) liegt, ist eine Ermessensfrage des SL.
