# `=this.file.name`
Eine Kreatur kann nur [[Fliegen]] wenn sie eine separate [[Bewegungsrate]] dafür hat.

Wird eine fliegende Kreatur zu Boden gestoßen, ihre [[Bewegungsrate]] auf 0 reduziert, oder auf andere Weise bewegungsunfähig gemacht, stürzt sie ab (siehe [[Stürzen]]).
Dies wird nur verhindert wenn die Kreatur [[Schweben]] kann oder anderweitig (z.B. durch Magie) in der Luft gehalten wird.
