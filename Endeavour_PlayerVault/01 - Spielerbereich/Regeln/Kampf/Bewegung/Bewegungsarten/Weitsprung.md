# `=this.file.name`

>[!info] Weitsprung
>Maximale Entfernung = ([[Stärke]] x 2 +10) x 0,3m (x 2 wenn min. 3 Meter Anlauf)

Jeder gesprungene Meter kostet einen Meter [[Bewegungsrate]].
Das Überspringen eines niedrigen Hindernisses erfordert einen erfolgreichen Wurf auf [[Athletik]] gegen [[Schwierigkeitsgrad]] 10.
Wenn die Kreatur dabei in schwierigem Gelände landet wird ein erfolgreicher Wurf auf [[Akrobatik]] gegen [[Schwierigkeitsgrad]] 10 nötig.

## Springen im Kampf
Während eines Kampfes kann eine Kreatur eine Distanz gleich ihrer Sprungweite /1,5 (abgerundet) ohne einen Würfelwurf springend zurücklegen.
Sie kann sich auch entscheiden ein Kästchen weiter zu springen (Sprungweite /1,5 aufgerundet).
In diesem Fall muss sie aber einen Wurf auf [[Athletik]] mit [[Schwierigkeitsgrad|SG]] 10 ablegen.
