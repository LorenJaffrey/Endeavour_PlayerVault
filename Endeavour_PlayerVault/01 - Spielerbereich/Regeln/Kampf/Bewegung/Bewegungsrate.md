# `=this.file.name`
Die Bewegungsrate wird meist durch die [[Abstammungen|Abstammung]] festgelegt und beträgt in den meisten Fällen 9m (6 Kästchen) pro [[Zug]].
Sie bestimmt wie weit sich eine Kreatur im Kampf pro Zug bewegen kann.
Eine Kreatur kann auch eine eigene Bewegungsrate für bestimmte Fortbewegungsarten wie [[Schwimmen]], [[Fliegen]], [[Graben]], etc. besitzen.
