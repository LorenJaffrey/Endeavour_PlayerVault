# `=this.file.name`
Zu Beginn einer [[Verhandlungen|Verhandlung]] bringt ein Held ein Argument vor, warum der NSC den Helden helfen sollte. 
Dieses kann ein Angebot enthalten (z. B. Banditen vertreiben, einen Schatz übergeben, einen Drachen töten) oder darauf abzielen, den NSC davon zu überzeugen, dass die Hilfe in seinem eigenen Interesse oder moralisch geboten ist.
Argumente müssen begründet sein. 
„Es ist gut für dich" reicht nicht – der Held muss erklären, warum. 
Ein NSC kann ansonsten nachhaken. 
Die Spieler können das Argument gemeinsam planen, auch wenn es letztlich von einem Helden vorgetragen wird.

## Fertigkeit wählen
Für ein Argument wird eine von drei Präsenz-Fertigkeiten genutzt – abhängig davon, wie der Held vorgeht:

- **[[Überzeugung]] – der Standardfall.** Jedes Argument, das nicht ausdrücklich lügt oder droht, läuft über [[Überzeugung]]. 
  Der Normalfall für ehrliche, logische oder emotionale Appelle an eine [[Motivationen|Motivation]].
- **[[Täuschung]] – die Lüge.** Enthält das Argument eine bewusste Lüge (falsches Versprechen, erfundene Tatsache, vorgetäuschte Identität), wird auf [[Täuschung]] gewürfelt.
- **[[Einschüchterung]] – der Druck.** Der Held setzt auf Machtdemonstration oder unterschwellige Drohung statt auf Überzeugung – ohne offen mit Gewalt zu drohen (das beendet die Verhandlung sofort, siehe „Die Drohung von Gewalt" in [[Verhandlungen]]).

Beide Sonderfälle – [[Täuschung]] und [[Einschüchterung]] – haben eigene Konsequenzen bei Misserfolg, siehe unten.

## Probe
Es wird gegen den [[Schwierigkeitsgrad|SG]] der aktuellen [[Einstellungen|Einstellung]] des NSC gewürfelt.
- **Motivation getroffen**: Das Argument spricht eine noch nicht genutzte [[Motivationen|Motivation]] des NSC an. SG -5.
- **Neutral**: Das Argument spricht keine [[Motivationen|Motivation]] an. SG unverändert.

| Test | Motivation | Neutral |
| --- | --- | --- |
| [[Misserfolg#Kritischer Misserfolg]] | [[Interesse]] -2; [[Geduld]] -2 | [[Interesse]] -2; [[Geduld]] -3 |
| [[Misserfolg#Erheblicher Misserfolg]] | [[Interesse]] -1; [[Geduld]] -2 | [[Interesse]] -2; [[Geduld]] -2 |
| [[Misserfolg#Deutlicher Misserfolg]] | [[Interesse]] -1; [[Geduld]] -1 | [[Interesse]] -1; [[Geduld]] -2 |
| [[Misserfolg#Knapper Misserfolg]] | [[Geduld]] -1 | [[Interesse]] -1; [[Geduld]] -1 |
| [[Erfolg#Knapper Erfolg]] | [[Interesse]] +1; [[Geduld]] -1 | [[Geduld]] -1 |
| [[Erfolg#Deutlicher Erfolg]] | [[Interesse]] +1 | [[Interesse]] +1; [[Geduld]] -1 |
| [[Erfolg#Erheblicher Erfolg]] | [[Interesse]] +2 | [[Interesse]] +1 |
| [[Erfolg#Kritischer Erfolg]] | [[Interesse]] +2; [[Geduld]] +1 | [[Interesse]] +2 |

Interesse kann durch ein einzelnes Argument nie über 5 und Geduld nie über den Startwert der [[Einstellungen|Einstellung]] hinaus steigen.

Ein besonders gut gespieltes Argument kann vom Spielleiter direkt als voller [[Erfolg]] gewertet werden. 
Wird dieselbe [[Motivationen|Motivation]] erneut angesprochen, steigt das [[Interesse]] nicht und die [[Geduld]] sinkt um 1.
Wenn ein Argument mehrere [[Motivationen]] anspricht, entscheidet der Spielleiter, welche zählt, oder lässt den Spieler wählen.
Wird dasselbe Argument erneut verwendet, zählt es automatisch als [[Misserfolg]].

## Fallstrick verwendet
Verwendet ein Argument einen der [[Fallstricke]] eines NSC, **scheitert es automatisch – es wird keine Probe gewürfelt.** 
[[Interesse]] und [[Geduld]] sinken dabei jeweils fix um 1, unabhängig davon, wie gut das Argument sonst formuliert oder gespielt war. 
Der NSC kann die Helden zusätzlich warnen, ihn nicht noch einmal so zu behandeln.

## Täuschung
Scheitert ein Argument, das auf [[Täuschung]] basiert, kann der Spielleiter entscheiden, dass der NSC die Lüge durchschaut und zusätzliches Misstrauen entwickelt: [[Interesse]] −1 zusätzlich.

## Einschüchterung
Scheitert ein Argument, das auf [[Einschüchterung]] basiert, kann der Spielleiter entscheiden, dass sich der NSC bedroht statt überzeugt fühlt: [[Interesse]] −1 zusätzlich.
Zudem merkt sich der NSC die Behandlung: Bei jeder zukünftigen [[Verhandlungen|Verhandlung]] mit denselben Helden gilt ein Einschüchterungs-Argument automatisch als [[#Fallstrick verwendet|Fallstrick]] – unabhängig vom Wurf –, bis die Helden das Verhältnis aktiv wiedergutmachen (Spielleiter-Ermessen, z. B. durch ein Geschenk oder eine erwiesene Gefälligkeit).
