# `=this.file.name`
`=this.Beschreibung`

Während einer langen Rast kann ein Charakter [[Wache halten]]. 
Der Charakter ist in dieser Zeit aufmerksam und kann auf mögliche Gefahren reagieren. 
Der SL kann für heimliches Nähern oder auffällige Bewegungen passende Proben oder einen Wurf auf [[Wahrnehmung]] verlangen. 

Ein Charakter kann bis zu 2 Stunden ohne Abzüge [[Wache halten]].
Ab der dritten Wachstunde erleidet er einen Malus von -2 auf [[Wahrnehmung]] und auf die [[Wahrnehmung#Passive Wahrnehmung]].
Dieser Malus stapelt sich für jede weitere Wachstunde (3. Stunde: -2, 4. Stunde: -4, 5. Stunde: -6, usw.).
