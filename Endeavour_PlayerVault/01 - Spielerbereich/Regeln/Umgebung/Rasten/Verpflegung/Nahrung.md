# `=this.file.name`
[[Nahrung]] wird in der Mengeneinheit [[Ration]] verwaltet. 
Eine [[Ration]] entspricht dabei 1 Pfund [[Nahrung]].
Ein Charakter benötigt 1 [[Ration|Ration]] pro Tag und kann länger damit auskommen, indem er nur halbe [[Ration|Rationen]] isst.

## Bedarf an `=this.file.name`
| Kreaturengröße |     Bedarf pro Tag      |
| -------------- |:-----------------------:|
| [[Winzig]]     |     1/4 [[Ration]]      |
| [[Klein]]      |      1 [[Ration]]       |
| [[Mittelgroß]] |      1 [[Ration]]       |
| [[Groß]]       | 4 [[Ration\|Rationen]]  |
| [[Riesig]]     | 16 [[Ration\|Rationen]] |
| [[Gigantisch]] | 64 [[Ration\|Rationen]] |

## Aufnahme von Nahrung  reduzieren
Reduziert ein Charakter die zu sich genommene [[Nahrung]] auf die Hälfte, zählt jeder Tag als halber Tag ohne Essen. 

Steht dem Spieler an einem Tag keine [[Nahrung]] zur Aufnahme zur Verfügung, so muss er einen [[Konstitutionsrettungswürfe|KO-Rettungswurf]] gegen [[Schwierigkeitsgrad|SG]] 10 ablegen.
Jeder folgende Tag ohne [[Nahrung]] erhöht den [[Schwierigkeitsgrad|SG]] um 1.
Schlägt die Probe fehl, erhält der Charakter eine Stufe [[Erschöpfung]].
